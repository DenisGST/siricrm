# Входящие сканы — инструкция пользователя

Бумажные документы, отсканированные на офисном МФУ, автоматически попадают в SiriCRM,
в раздел **«Входящие сканы»**. Оттуда сотрудник привязывает скан к клиенту: файл
ложится в папку клиента, при необходимости заводится запись корреспонденции или
фиксируется ответ на запрос в госорган.

Инструкция состоит из двух частей:

- **Часть 1** — установка программы-агента на офисный компьютер (делается один раз,
  обычно системным администратором).
- **Часть 2** — ежедневная работа с лотком сканов в CRM (для секретаря, юриста,
  бухгалтера).

---

## Как это работает

```
Бумага → МФУ («Сканировать в папку») → папка на офисном ПК/сетевом диске
       → агент SiriCRM (следит за папкой, отправляет файл в CRM)
       → лоток «Входящие сканы» в CRM → привязка к клиенту
```

Сервер CRM стоит в облаке и не видит офисную сеть, поэтому файлы **отправляет
маленькая программа на офисном компьютере** (агент). Она сидит в трее рядом с часами
и раз в несколько секунд заглядывает в папку сканера: появился новый файл — отправила
в CRM.

# Часть 1. Установка агента на офисный компьютер

## Что нужно получить у администратора заранее

| Что | Пример | Зачем |
| --- | --- | --- |
| **Адрес приёма** | `https://siricrm.ru/scans/agent/intake/` | Куда отправлять файлы |
| **Токен** | длинная строка | Пароль агента, без него CRM файл не примет |
| **Имя сканера** | `scanner-jur` | По нему CRM понимает, кому из сотрудников показывать эти сканы |

> ⚠ **Адрес и токен — всегда парой.** Токен от боевой CRM (`siricrm.ru`) не подойдёт
> к тестовой (`crmsiri.ru`) и наоборот — будет ошибка «CRM отклонила токен».

**Имя сканера** должно совпадать с полем «Имя сканера» в карточке сотрудника в CRM.
Сейчас в офисе заведено по одному сканеру на отдел:

- `scanner-jur` — юридический отдел;
- `scanner-docs` — отдел сбора документов;
- `scanner-buh` — бухгалтерия.

## Шаг 1. Установить Python

Скачать с [python.org](https://www.python.org/downloads/) версию 3.9 или новее.
При установке отметить галочки:

- ✅ **Add Python to PATH** (внизу первого окна установщика);
- ✅ **tcl/tk and IDLE** — без неё не откроется окно настроек агента.

## Шаг 2. Скопировать файлы агента

Скопировать папку `tools/scan-agent` из репозитория проекта на офисный ПК, например
в `C:\siri-scan-agent\`. В ней должны лежать:

```
scan_agent.py           — сама программа
requirements.txt        — список зависимостей
config.ini.example      — образец настроек
start_agent.bat         — запуск двойным кликом
install_autostart.bat   — добавить в автозагрузку Windows
remove_autostart.bat    — убрать из автозагрузки
```

## Шаг 3. Установить зависимости

Открыть командную строку в папке агента (в проводнике: `Shift` + правый клик по
пустому месту → «Открыть окно PowerShell здесь») и выполнить:

```
pip install -r requirements.txt
```

## Шаг 4. Первый запуск и настройка

Двойной клик по **`start_agent.bat`** — рядом с часами появится иконка агента
(сначала красная — он ещё не настроен).

Правый клик по иконке → **«Настройки…»** (или просто двойной клик по иконке).
Откроется окно, заполнить поля:

| Поле | Что вводить |
| --- | --- |
| **Папка сканера** | Папка, куда МФУ кладёт сканы. Локальная (`C:\Scans`) или сетевая (`\\NAS\scans\siri`) |
| **Адрес приёма CRM** | `https://siricrm.ru/scans/agent/intake/` |
| **Токен** | Токен от администратора |
| **Имя сканера** | `scanner-jur` / `scanner-docs` / `scanner-buh` — **обязательно** |
| **Папка для залитых** | Куда убирать уже отправленные файлы, напр. `C:\Scans\_uploaded`. Можно оставить пустым |
| **Хранить залитые, дней** | Через сколько дней удалять из папки залитых. По умолчанию 3, `0` — не удалять |
| **Пауза стабилизации, сек** | Сколько ждать, пока МФУ дозапишет файл. По умолчанию 3 |
| **Интервал опроса папки, сек** | Как часто заглядывать в папку. По умолчанию 5 |
| **Проверять TLS-сертификат** | Оставить включённым |

Нажать **«Проверить связь»** — должно появиться зелёное «✓ Связь с CRM есть, токен
принят». Затем **«Сохранить»** — агент перезапустится сам, иконка станет зелёной.

> Настройки можно заполнить и заранее в файле: скопировать `config.ini.example` →
> `config.ini` и отредактировать в блокноте.

## Шаг 5. Настроить МФУ

На панели МФУ (или в его веб-интерфейсе) настроить функцию **«Сканировать в папку»
/ «Scan to SMB»** на ту же папку, что указана в поле «Папка сканера».

Агент забирает файлы с расширениями `.pdf`, `.tif`, `.tiff`, `.jpg`, `.jpeg`, `.png`.
Всё остальное игнорирует.

## Шаг 6. Добавить в автозагрузку

Чтобы агент запускался сам при включении компьютера — **один раз** запустить
**`install_autostart.bat`**. Он добавит агент в автозагрузку Windows и предложит
запустить сразу.

Убрать из автозагрузки — `remove_autostart.bat` (сам агент при этом не
останавливается: закройте его в трее → «Выход»).

## Иконка в трее — что означает цвет

| Цвет | Что значит | Что делать |
| --- | --- | --- |
| 🟢 **зелёный** | Всё работает, следит за папкой, связь с CRM есть | Ничего |
| 🟠 **оранжевый** | Последняя отправка не удалась (сеть/сервер), агент повторит попытку | Подождать; если не проходит — проверить интернет |
| 🔴 **красный** | Нет связи, не настроен или папка не найдена | Открыть «Настройки…» → «Проверить связь» |
| ⚪ **серый** | Запускается | Подождать пару секунд |

Наведите мышь на иконку — во всплывающей подсказке текущий статус и счётчик
отправленных файлов.

**Правый клик по иконке** — меню:

- **Проверить связь** — проверка доступности CRM и токена;
- **Перезапустить слежение** — если папка временно отваливалась;
- **Открыть папку сканов** — открывает папку в проводнике;
- **Настройки…** — окно настроек (см. Шаг 4);
- **Открыть config.ini** — файл настроек в блокноте;
- **Открыть лог** — журнал работы (что и когда отправлено, ошибки);
- **Выход** — остановить агент.

## Что происходит с файлом на компьютере

1. Агент видит новый файл и ждёт, пока МФУ его дозапишет.
2. Отправляет в CRM.
3. Если отправка удалась — переносит файл в «папку для залитых».
4. Раз в час удаляет из этой папки файлы старше заданного числа дней (по умолчанию 3).

Так папка не растёт бесконечно, но пара дней «буфера» остаётся на случай разбора
спорных сканов. Если отправка не удалась — файл остаётся на месте и будет отправлен
при следующей попытке, ничего не теряется.

# Часть 2. Работа с лотком «Входящие сканы» в CRM

## Где находится и кому доступен

Пункт меню **«Входящие сканы»** (🖨️) в боковом меню CRM. Доступ выдаёт администратор
галочкой в карточке сотрудника — сейчас он есть у юридического отдела, отдела сбора
документов и бухгалтерии.

Рядом с пунктом меню — **красный бейдж** с числом непривязанных сканов с вашего
сканера. Когда приходит новый скан, всплывает уведомление.

## Что видно в лотке

Лента карточек: имя файла, дата, сканер-источник и **превью PDF прямо на странице** —
можно прочитать документ, не скачивая.

Фильтры сверху:

- **Поиск по имени файла**;
- **Выпадашка «сканер»** — по умолчанию показывает сканы вашего отдела, но можно
  выбрать чужой сканер или **«Все сканеры»** (например, юристу — посмотреть сканы
  секретаря). Это фильтр, а не запрет: чужие сканы доступны;
- **Источник** — «Сканер» или «Загрузка вручную»;
- **Архив отклонённых** — что было отклонено (для разбора: кто и когда).

## Привязать скан к клиенту

1. Кнопка **«Привязать к клиенту»** на карточке скана.
2. **Клиент** — начните вводить фамилию, имя или телефон, выберите из подсказок.
3. **Папка клиента** — куда положить файл. По умолчанию подставляется папка «Сканы».
4. **Имя файла** — можно переименовать (`scan_0012.pdf` → `Ответ Росреестра.pdf`).
5. При необходимости — две дополнительные галочки (ниже).
6. **«Привязать»**.

Скан исчезает из лотка и появляется в файлах клиента.

### Галочка «Завести запись входящей корреспонденции»

Если это входящее письмо, которое нужно учесть в корреспонденции клиента:

- **Услуга** — по какой услуге переписка;
- **Контрагент** — от кого письмо (поиск по реестру: банк / МФО / госорган);
- **Тип письма** — например, «Ответ из Росреестра»;
- **Дата документа**.

### Галочка «Это ответ на запрос в госорган (БФЛ)»

Если пришёл ответ на ранее отправленный запрос:

- **Запрос** — выбрать из списка запросов клиента, ожидающих ответа
  (показываются с исходящим номером и адресатом);
- **Дата ответа**.

Скан станет сканом ответа на этот запрос, а статус запроса в карточке дела
переключится на **«Ответ получен»** — просрочка по нему больше не считается.

## Привязать несколько сканов сразу

Если пришёл многостраничный пакет от одного клиента: отметьте карточки
**чекбоксами** → кнопка **«Привязать выбранные»** → выбрать одного клиента и одну
папку → **«Привязать все»**.

При пакетной привязке нельзя переименовать файлы и завести корреспонденцию —
это только быстрая раскладка по папке.

## Отклонить скан

Кнопка **«Отклонить»** — для мусора и пустых страниц. Файл удаляется из хранилища,
но запись остаётся в **архиве отклонённых** (видно, кто и когда отклонил).

## Загрузить файл вручную

Кнопка **«Загрузить»** вверху лотка — выбрать файлы с компьютера. Они попадут в тот
же лоток и привязываются так же. Удобно, когда документ пришёл по почте или на
телефон, а не через МФУ.

## Если что-то не работает

| Симптом | Причина и что делать |
| --- | --- |
| Иконка агента **красная** | Не заполнены настройки или нет связи. Правый клик → «Настройки…» → «Проверить связь» |
| **«CRM отклонила токен»** | Адрес и токен от разных серверов либо токен сменили. Запросить актуальный у администратора |
| Скан положили, **в CRM не появился** | Проверить: (1) папка в настройках — та самая, куда кладёт МФУ; (2) расширение файла из списка разрешённых; (3) трей → «Открыть лог» — там будет причина |
| Агент **не стартует слежение** | Не заполнено «Имя сканера» — оно обязательное |
| Сканы **не видны в лотке** | В выпадашке «сканер» выбран чужой сканер. Переключить на свой или «Все сканеры» |
| **Нет пункта меню** «Входящие сканы» | Не выдан доступ — попросить администратора поставить галочку в карточке сотрудника |
| Иконка **пропала** после перезагрузки ПК | Агент не в автозагрузке — запустить `install_autostart.bat` |

Журнал агента — файл `scan-agent.log` рядом с `config.ini` (трей → «Открыть лог»).
В нём видно каждый отправленный файл и текст любой ошибки — это первое, что стоит
посмотреть и приложить к обращению.
